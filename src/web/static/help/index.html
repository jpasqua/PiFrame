Overview

PiFrame is a simple digital picture frame that does not require a service to store your photos. Everything stays right on your picture frame. The frame itself just displays photos. You control everything from your phone, tablet or computer.

Local by design. Photos, albums, and settings are stored on the frame. The owner workspace is not a public website, and it currently has no sign-in screen. Use PiFrame only on a trusted network.

On its very first start, PiFrame creates a temporary Wi‑Fi network so you can give it the credentials for your home network. Once it joins, the temporary setup network disappears and the frame begins its normal startup.

First connection: Wi‑Fi setup

  1. Connect power to the frame and wait for it to start. Keep your phone, tablet, or computer nearby.
  2. Open that device’s Wi‑Fi settings and join the network named PiFrame Setup-XXXX. The final four characters identify this particular frame. This is a temporary, open setup network.
  3. After joining, the device should open the PiFrame setup page automatically. If it does not, open a browser; many devices show a “Sign in to Wi‑Fi network” notice that leads to the same page.
  4. Choose your home Wi‑Fi network from the list, enter its password, and submit it. Wait while the frame joins the network.
  5. Reconnect your phone, tablet, or computer to that same home Wi‑Fi network. The PiFrame setup network is no longer needed.

During setup, internet access may pause. Your device is connected directly to PiFrame’s temporary network, not your usual Wi‑Fi. If the portal does not appear, verify that you joined the PiFrame Setup-XXXX network and then open a browser.

When PiFrame has finished starting, open its owner workspace from another device on the same network. Use its local hostname in a browser: http://<frame-hostname>.local. If you do not know the hostname or address, open System Status once you can reach the workspace; it shows the current host name and IP address.

If a saved Wi‑Fi network cannot be joined on a later boot, PiFrame waits briefly and then opens the same temporary setup network again. Repeat the steps above to select a working network.

Quick start

  1. Open the owner workspace and select Albums.
  2. Create an album, open it, and upload a few photos.
  3. Return to Dashboard to confirm that photos are ready.
  4. Use Open frame, or look at the attached display, to see the slideshow.

New photos are prepared in the background. A photo may briefly show as processing before it is available to the frame.

Views and controls

On the frame

Display

This is the full-screen slideshow on PiFrame’s attached display. It has no controls during normal viewing.

  • With no ready photos, it shows a waiting message.
  • When a daily schedule is off, the screen is black.
  • Depending on Presentation settings, it can show one photo or an adaptive arrangement of one, two, or three photos; the optional clock appears at the upper left.
  • When enabled, weather appears at the lower right. PiFrame hides it if weather data is unavailable.
Owner workspace

Dashboard

The starting view gives a quick picture of the frame: whether it is displaying, which albums are used, layout, timing, schedule state, and library health.

  • Open frame opens the slideshow in the browser.
  • Manage albums goes directly to the album list.
  • The library counts separate ready photos from those still preparing or needing attention.
Owner workspace

Frame

Use this view to manage settings specific to this physical frame.

  • Frame name and Frame description identify the frame in the workspace. Saving the name does not change the device’s network hostname.
  • Location can be searched to set the frame’s place; the advanced section lets you review or set the time zone. The time zone drives the clock and schedule.
  • Weather requires a selected location. Enter a city, region, country, or postal code, choose Search location, select the matching result, and save the Frame settings. Selecting a result stores the coordinates that weather needs. Typing or changing the location text without selecting a search result clears those coordinates; search and select again before saving.
  • Display orientation rotates the slideshow to match how the physical screen is mounted.
Owner workspace

Presentation

Choose what the frame plays and how it looks.

  • Select Use all albums, or uncheck it and choose only the albums you want displayed.
  • Set seconds per photo and an ordering method: random, filename, upload date, or the manual photo order set inside an album.
  • Choose One photo or Adaptive. Adaptive selects balanced multi-photo layouts when suitable photos are available.
  • Use Fit entire photo to preserve the whole image, or Fill screen and crop edges for edge-to-edge presentation.
  • Turn on the clock and choose its format, size, and whether to show the date. Choose a transition and its duration for slide changes.
  • Turn on Show weather, then choose Current conditions, 5-day forecast, or both, and select Imperial or Metric units. Current conditions show temperature, an icon, and wind; the forecast shows each day’s high, low, and icon. When both are selected, PiFrame alternates them between slides.
  • Weather will not appear until a location has been selected and saved in Frame.
Owner workspace

Schedule

Set when the display should be on each day. When it is off, PiFrame shows a black screen rather than turning the device off.

  • Enable the daily schedule, then set the on and off times in the frame’s local time.
  • Follow schedule returns to those times.
  • Force frame on and Force frame off are immediate overrides until you switch back to Follow schedule.
Owner workspace

Albums

Albums organize the photo library. Create a new album in the bottom row, rename an existing album, or open its arrow to manage its photos.

  • The photo count tells you how many photos belong to each album.
  • Deleting an album also deletes its contained photos and their managed copies. PiFrame asks for confirmation twice because this cannot be undone.
Album detail

Photos and upload queue

Opening an album takes you to its photo-management view.

  • Choose one or more supported image files, then select Upload. The queue tracks each file as it uploads and is processed.
  • If a filename already exists in the album, choose Keep both, Replace, or Skip. Resolve marked duplicates before uploading.
  • Detail lists file name, dimensions, size, and actions. Grid shows thumbnails.
  • Sort by manual order, newest upload, or name. In manual order, drag photos in the grid to set the slideshow sequence; use Presentation’s manual ordering to play that sequence.
  • Rotate left or right to correct an image without altering the original. Retry a failed processing job, or delete an individual photo when it is no longer wanted.
Owner workspace

System Status

This is the maintenance and troubleshooting view.

  • System shows the platform, local host name/address, and data locations.
  • Storage lists where originals, thumbnails, and display assets are kept.
  • Recent activity records useful events such as uploads and settings changes.
  • On a Raspberry Pi, the Power section can restart or shut down the entire device. After shutdown, wait until the display is dark before removing power.
Overlay

About PiFrame

Select the PiFrame logo in the workspace to open the About window. It briefly describes the local-first design and shows version and attribution information. Close it to return to the current view.

Everyday care

When something looks wrong

  • If a new image is not visible yet, give its processing status a moment and check Dashboard or the album detail view.
  • If the display is black unexpectedly, check Schedule for an active off period or a Force frame off override.
  • If you cannot reach the workspace, confirm your controlling device and PiFrame are on the same network. A failed saved connection will make PiFrame offer its temporary setup network again.
  • Use System Status before restarting; its recent activity can help identify what happened.
